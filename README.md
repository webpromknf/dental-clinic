# Clínica Oral Lumina - showroom dentário

Pasta estática pronta para GitHub Pages.

## Deploy

1. Enviar o conteúdo desta pasta para `https://github.com/webpromknf/dental-clinic`.
2. Ativar GitHub Pages em Settings > Pages > Deploy from a branch > main > root.
3. Abrir o URL publicado pelo GitHub Pages.

## Funcionalidades demo

- PT/EN/ES com links WebPromk por idioma.
- Sistema de marcação multi-passo em JavaScript.
- Tratamentos, equipa, resultados antes/depois, testemunhos, blog e páginas legais.
- Formulários estáticos simulados, sem envio real.
